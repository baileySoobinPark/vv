## Integration Pathways

### General Steps for All VASPs

1. Onboarding
   1. Complete the registration and onboarding process for VerifyName.

For Regulated VASPs\
​

1. Connecting with Enclave\
   Set up the Enclave server to enable secure communication with VerifyVASP Central Server.
2. ​Testing with Robot VASP\
   Validate pre-verification workflows by simulating transactions.

For Unregulated VASPs

1. ​Implementing VASP API

* Develop the VerifyName API to support post-verification requests.

1. ​Testing with Robot VASP

* Ensure the implemented API functions correctly with simulated requests.\
  Explore each step for specific instructions and recommendations tailored to your VASP’s operational role.
