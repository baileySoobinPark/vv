## Purpose

The primary aim of this document is to:

* Provide a clear understanding of TravelRule's and VerifyName's TravelRule's functionalities, architecture, and integration flows.
* Offer step-by-step guidance for developers implementing VerifyVASP.
* Explain compliance requirements and how VerifyVASP aligns with the Travel Rule.

<br />

## Scope of This Document

This document includes:

* Integration guides for setting up the Enclave.
* Process flows and architectural overviews.
* API specifications with detailed request and response examples.
* Best practices for efficient and secure implementation.

<br />

## Out of Scope

This document does not:

* Provide in-depth details about the underlying blockchain or cryptographic mechanisms.
* Include regulatory interpretations for specific jurisdictions.
* Offer support for integrating third-party tools outside of VerifyVASP’s scope (e.g., external KYT tools or sanction screening services).
