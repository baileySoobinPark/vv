# Overview

Deposit scenario testing covers two cases:

* **Pre-Verification Deposit Test** – Assumes receiving from a VASP with regulatory obligations.
* **Post-Verification Deposit Test** – Assumes receiving from a VASP without regulatory obligations.

Run each scenario to verify your VASP’s implementation of the VerifyName protocol.

### 2. Report Verification Result Test

* **조건**
  * Result Report Simulation API를 호출해 RobotVASP가 최종 검증 결과를 보고하도록 명령합니다.

    <Accordion title="Resuit Report Simulation API 호출 예시" icon="fa-info-circle">
      **Method**: `POST`

      * **Endpoint**: `<RobotVASP URL>/vega/robot/v2.0/action/owner-verifications/{request_id}/result`

        * **요청 body 예시**

          ```json
          {
            "verification_result": "VERIFIED"
          }
          ```
          ```json
          {
            "verification_result": "DENIED",
            "reason": "MISMATCH-ADDRESS",
            "message": "mismatch address"
          }
          ```
          ```json
          {
            "verification_result": "ERROR",
            "reason": "TRANSFER-ERROR",
            "message": "test error"
          }
          ```

        * **결과 예시**
          ```json
          {
            "result": true
          }
          ```

        * 추가적인 Body 예시는 Enclave API 중 [Result Report API]()  API 문서에서 확인할 수 있습니다.
    </Accordion>
* **기대 결과**
  * 귀사의 VASP가 구현한 Callback API에 의해 RobotVASP가 보고한 최종 검증 결과가 전달됩니다.
  * callback의 타입이 `OWNER_VERIFICATION_RESULT_REPORT` 인지 확인합니다.

<br />

**\[선행 조건 2.]** RobotVASP withdrawal API를 호출해 RobotVASP가 귀사의 VASP가 관리 중인 지갑 주소로 가상 자산을 전송하도록 명령합니다.

<Accordion title="RobotVASP Withdrawal API 호출 예시" icon="fa-info-circle">
  **Method**: `POST`

  * **Endpoint**: `<RobotVASP URL>/v2.0/action/owner-verifications/{request_id}/withdrawal`
    * **RobotVasp KR**: [https://api-kr.verifyvasp.xyz/vega/robot](https://api-kr.verifyvasp.xyz/vega/robot)
    * **RobotVasp Global**: [https://api.verifyvasp.xyz/vega/robot](https://api.verifyvasp.xyz/vega/robot)

  * **요청 쿼리 파라미터**

    | Parameter Name              | required | Type    | Description                                                              | Example                                    |
    | --------------------------- | -------- | ------- | ------------------------------------------------------------------------ | ------------------------------------------ |
    | `ticker`                    | required | string  | 전송할 가상 자산의 Ticker                                                        | "ETH"                                      |
    | `originator_account_number` | required | string  | 가상 자산을 송신할 지갑 주소                                                         | 0xb0bFf9721871e22653358956cf59a5FdBF3D752F |
    | `originator_tag`            | optional | string  | 2차 주소가 있는 address를 검증하기 위한 tag                                           | 123456789                                  |
    | `amount`                    | optional | string  | 전송할 가상 자산의 수량                                                            | "0.0005"                                   |
    | `omit_tx_report`            | optional | boolean | 가상 자산 전송 후 트랜잭션 ID(트랜잭션 Hash) 보고 실행 여부를 판단하는 필드. <br /> 기본 값은 false 입니다. | false                                      |

  * **요청 body 예시**

    ```json
    {
      "ticker": "ETH",
      "originator_account_number": "0xFa230E9cCAF5e382539147294d7965Eeccbbfa5c",
      "amount": "0.001",
      "omit_tx_report": true
    }
    ```

  * **결과 예시**
    ```json
    {
      "tx_hash": "0x6CED59A8D2dA7bdf3E6c2920F632421A8f3c34D2"
    }
    ```
</Accordion>

<br />

* **조건**
  * Robot Withdrawal API를 호출할 때, 요청 body의 `omit_tx_report` 필드를 false로 설정하여 호출한 경우, 트랜잭션 ID(트랜잭션 Hash)를 자동으로 보고합니다.
* **기대 결과**
  * 귀사의 VASP가 구현한 Callback API를 통해 트랜잭션 ID(트랜잭션 Hash)가 전달됩니다.
  * callbackType이 `OWNER_VERIFICATION_TX_REPORT`인지 확인합니다.
    * 입금 반영에는 최대 20분이 소요될 수 있습니다.

### 3. Report Verification Result Test

* **조건**
  * 귀사의 VASP는 RobotVASP가 반환한 검증 결과를 기반으로 최종 검증 결과를 판단하여 보고합니다.

    <Accordion title="Result Report API 호출 예시" icon="fa-info-circle">
      **Method**: `POST`

      * **Endpoint**: `/v2/owner-verifications/{request_id}/result`

        * **요청 쿼리 파라미터**

        | Parameter Name        | Type   | Description                                                           | Example                                                                                                                                                                                                                           |
        | --------------------- | ------ | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
        | `verification_result` | enum   | 최종 검증 결과                                                              | `VERIFIED`, `DENIED`, `ERROR`                                                                                                                                                                                                     |
        | `reason`              | enum   | verification\_result가 `DENIED` 혹은 `ERROR`인 경우, 결과에 대한 이유를 명시한 필드      | `MISMATCH-TICKER` , `MISMATCH-NETWORK`, `MISMATCH-ADDRESS`, `MISMATCH-NAME`, `MISMATCH-DTI`, `MISMATCH-DATE-OF-INCORPORATION`, `MISMATCH-BIRTH-DATE`, `MISMATCH-ORGANISATION-IDENTIFICATION`, `TRANSFER-ERROR`, `UNDEFINED-ERROR` |
        | `message`             | string | verification\_result가 `DENIED` 혹은 `ERROR`인 경우, `reason`을 상세하게 설명하는 필드 | transfer error                                                                                                                                                                                                                    |

        * **요청 body 예시**

        ```json
        {
            "verification_result": "VERIFIED"
        }
        ```
        ```json
        {
            "verification_result": "DENIED",
            "reason": "MISMATCH-ADDRESS",
            "message": "mismatch address"
        }
        ```
        ```json
        {
            "verification_result": "ERROR",
            "reason": "TRANSFER-ERROR",
            "message": "test error"
        }
        ```

        * **결과 예시**

        ```json
        {
          "result": true
        }
        ```

        * 추가적인 Body 예시는 Enclave API 중 [Result Report API]()  API 문서에서 확인할 수 있습니다.
    </Accordion>
* **검증 결과**
  * 귀사의 VASP가 최종적으로 판단한 검증 결과에 따라 가상 자산 입금 반영 여부를 판단합니다.
